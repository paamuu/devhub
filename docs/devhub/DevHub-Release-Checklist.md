## 正式发布前仍需完成

1. **依赖安全处置**：`npm audit` 为 0 中等、10 高风险项，均由 picomatch 及其上层依赖链计入，不是 10 个独立漏洞。公告为 [GHSA-fc5q-39xc-vjpf](https://github.com/advisories/GHSA-fc5q-39xc-vjpf)，受影响范围 `<=4.0.7`，本轮官方 latest 仍是 4.0.7。等待已修复上游版本后更新、重新审计及构建验证；不自动采用 audit 提议的旧版工具链。此前 minimatch 风险通过精确 override 11.0.9 解决。
2. **签名和发布资源**：提供代码签名凭据及正式图标，开启相应签名配置，重新构建并验证签名与安装体验。当前没有配置证书，不能宣称产物已签名。
3. **备份人工全链路**：在隔离 Windows 用户环境，通过原生文件选择器导出、选择备份、取消及确认恢复，验证真正的进程重启、启动结果提示、活动预览停止与缺失密钥提示。当前自动化覆盖核心服务恢复及数据库重开，没有代替原生对话框和 `app.relaunch()` 的完整交互验收。本轮隔离 UI 试运行未取得可见窗口，且启动日志出现运行服务初始化失败，原因尚未确认；临时入口已移除，最终安装版自动冒烟再次通过，仍需独立用户环境复查。
4. **升级矩阵**：现有测试覆盖历史 schema 迁移和同版本覆盖安装；仍需保留真实旧版本安装器，验证跨版本安装升级、旧数据迁移与应用配置保留。用不同 Windows 用户检查密钥不可解密的提示。
5. **完整 UI / 性能验收**：确认默认主题和主题数量，复核键盘焦点、最小窗口、系统缩放、长路径、长日志、大量项目列表及备份上限的体验，记录启动及列表响应的测量结果。已有截图与冒烟不等同于这一完整矩阵。

## 可复验命令

在 `devhub/` 中运行：

```powershell
npm ci
npm test
npm run typecheck
npm run format:check
npm run installer:win
npm run smoke -- release/win-unpacked/DevHub.exe
npm audit
npm outdated
```

已安装应用可用 `npm run smoke -- <安装目录>/DevHub.exe` 验证；该命令使用临时数据目录。安装器的覆盖安装和卸载会操作系统注册项，复验应使用专用 Windows 用户或已确认的测试副本，避免覆盖正在使用的正式安装。

备份仅覆盖 DevHub 管理数据，不恢复项目源码。恢复包上限 64 MiB，哈希用于发现损坏，不提供发布者身份认证。切换日志已验证进程中断回退，突然断电的物理落盘行为尚未通过硬件故障注入验证。
