# DevHub 实施计划

以 [PRD](DevHub-PRD-v0.1.md) 和 [TDD](DevHub-TDD-v0.1.md) 为准。首发验收平台为 Windows。DevHub 工程位于 `devhub/`。

| 阶段 | 任务 | 验收 |
| --- | --- | --- |
| M0 | 用 Developer Workbench 关键页面验证信息结构、密度和键盘操作。明确 SQLite 和 IPC 验证方式。 | 评审页面和待验证技术选型。 |
| M1 | 建立 Electron Main / 沙箱 Preload / Lit Renderer / Shared，锁定 npm 最新稳定直依赖，建立 SQLite 迁移和 Windows 打包。 | 类型检查、构建、隔离目录中的启动与重开、Windows 打包。 |
| M2 | 完成模板与项目登记、标签和筛选、路径重关联、归档、复制任务和中断恢复。 | 真实目录验证 Git 隔离、重复路径、取消、失败恢复和独立删除。 |
| M3 | 实现命令预览、停止进程树、会话与日志、就绪检测、安全注入环境变量、IDE 和浏览器入口。 | Windows 上用实际 Vite 项目验证成功、超时、端口冲突及退出清理。 |
| M4 | 实现工作树识别、Remote 管理、分支、基础状态和 GitHub 跳转。 | 使用临时工作树验证外部改动、嵌套路径和错误反馈。 |
| M5 | 完成备份恢复、UI 复核、Windows 安装包和发布验收。 | 按 PRD §12 逐项验证，并验证升级迁移和恢复失败时的回退。 |

每次引入 npm 直依赖用官方仓库的 `latest` 标签解析稳定版，保存精确版本及 lockfile。技术验证优先评估 Electron 运行时内置 SQLite 与原生 SQL，并通过 Windows 产物验证可用性。路由与组件库由原型验证决定。

## 当前进度

- M0 已有 Windows 关键导航和页面空状态原型。密集列表、创建向导及主题仍随业务页面评审。
- M1 已建立项目骨架、首条 SQLite 迁移与工作区状态 IPC。未签名 Windows x64 测试包已通过沙箱 Preload、渲染和 SQLite 重开验证。本轮采用 Electron 内置 SQLite 与原生 SQL，备份和恢复留到 M5 验证。
- M2 已实现本地模板与项目登记、编辑、筛选、标签、项目归档和恢复、路径状态检查、重关联、打开目录及移除记录。数据库升级至 schema 2，升级前保留一致性快照。目录通过系统选择器授权，同一规范路径在模板与项目之间去重。
- M2 已接入从模板创建项目。Templates 中输入项目名称，选择父目录后确认最终路径、排除规则及 Git 初始化方式。Projects 中查看持久化任务、取消复制或恢复中断任务。schema 3 保存任务阶段，成功登记与来源关系、模板使用时间在同一事务中提交。
- 创建任务跳过 Git 元数据、构建产物、敏感环境文件及目录链接。落位前中断且归属可验证时从临时目录重新复制，落位后失败可继续登记；无法验证归属时保留路径并提示检查。
- M2 已完成。实际目录回收经过主进程确认、目录身份复核和登记关系检查，成功后保留登记并显示路径失效。模板支持技术栈、来源仓库及默认预览配置，导入时读取本地项目特征供用户确认。创建项目时复制技术栈和预览配置，并独立保存来源模板名称快照。
- Dashboard 显示实际最近打开的项目、最近使用的模板和失效路径。模板及项目详情显示路径、元数据、时间和预览配置，支持从详情直接编辑、重关联、归档及删除操作。
- M3 已完成命令预览、停止与重启、HTTP/TCP 就绪检测、并行项目会话、日志、环境变量和密钥注入、IDE 配置与浏览器入口。schema 5 增加项目级 IDE 配置。Windows 打包版已验证实际 Vite 项目。
- M4 已完成 Git 工作树识别、Remote 管理、当前分支与基础状态，以及指定 Remote 的 GitHub.com 跳转。项目详情增加 Preview / Git 切换，Settings 增加系统 Git 检测。Git 信息实时读取，不新增数据库缓存或迁移。
- M5 已实现一致性备份恢复、维护期间 IPC 协调、恢复中断回滚、Settings 入口和 Windows x64 NSIS 安装器。31 项测试及实际安装版 M2–M5 冒烟通过；同版本覆盖安装和卸载检查通过。已完成候选包交付，正式发布仍有未关闭项，见 `DevHub-Release-Checklist.md`。

## 本地运行

在 `devhub/` 下使用 Node.js 22.22 或更新版本执行以下命令。首次启动会在 `~/.devhub/` 中创建数据库。`smoke` 使用隔离的临时目录。

当前构建与预览管理面向 Windows，构建需要系统 .NET Framework 4 的 `csc.exe`。本地开发日志位于 Electron userData 的 `logs/`，数据库、自定义环境变量与密钥仍统一位于 `~/.devhub/`。

```powershell
npm ci
npm test
npm run typecheck
npm run format:check
npm run build
npm run smoke
npm start
```

`npm run package:win` 生成未签名的 Windows 测试产物，目录为 `devhub/release/`。

`npm run installer:win` 生成同目录中的 NSIS 安装器。安装目录与 `~/.devhub/` 数据目录独立，卸载不会默认删除用户数据。

打包后的冒烟测试命令为 `npm run smoke -- release/win-unpacked/DevHub.exe`。
